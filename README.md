## 📖 Project Overview

SwitchOn Dashboard Project is a frontend-only project management dashboard designed to help teams organise projects, monitor progress, manage tasks and track important deadlines from a single, intuitive interface.

The application was developed as part of **Company Project 2** using modern frontend development practices. It demonstrates component-based architecture, responsive design, reusable UI components, TypeScript best practices and collaborative software development using Git and GitHub.

The project does not include a backend or authentication system. Instead, it consumes data from a mock API while new or updated data is managed using the Context API together with Local Storage to provide a realistic user experience.

# 🚀 Getting Started

## Prerequisites

Before running the project, ensure you have:

- Node.js (v20 or later)
- npm
- Git

---

## Clone the Repository

```bash
git clone https://github.com/Bafana-Ndlovu/SwitchOn-Dashborad-Projects.git
```

---

## Navigate into the Project

```bash
cd SwitchOn-Dashboard-Projects
```

---

## Install Dependencies

```bash
npm install
```

---

## Start the Development Server

```bash
npm run dev
```

The application will run at:

```
http://localhost:5173
```

---

## Build the Project

```bash
npm run build
```

---

## Preview the Production Build

```bash
npm run preview
```

---

## Run the Linter

```bash
npm run lint
```
